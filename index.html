ChromeLab

This app tests what an installed web app can do on a Chromebook. Install it first; several features only work in the app window.

Support on this device

Keyboard shortcuts

Ctrl+OOpen file
Ctrl+SSave
Ctrl+Shift+SSave as
Ctrl+1…5Switch tabs
Ctrl+Shift+NTest notification
F11Fullscreen with keyboard lock

Files

Opens and saves straight to your Files app. No download-and-reupload. After installing, right-click a .txt, .md or .json file in Files and pick "Open with ChromeLab".
